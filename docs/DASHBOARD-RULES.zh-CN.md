# 后台规则与订阅链接有效期

`v0.8.4-mgma.24` 增加管理端「安全与系统 → Clash 规则编辑器」。每行一条规则，按顺序匹配，支持 `#` 注释，最后一行必须是 `MATCH,目标`。页面列出可用的模板策略组、内置动作和规则集；例如：

```text
DOMAIN-SUFFIX,example.com,DIRECT
DOMAIN-SUFFIX,example.org,🚀 节点选择
MATCH,🐟 漏网之鱼
```

第一次打开显示现有文件模板中的规则；只有保存后才启用数据库规则。后台规则应用于下一次 Clash、Mihomo 和小火箭订阅下载，并把配置模式设为 `rule`。用户需要更新订阅，已导入客户端的旧配置不会被主动推送替换。节点、策略组、DNS 和规则提供者仍使用原模板与套餐授权；外部订阅只能贡献节点，不能覆盖后台规则。

保存会校验规则类型、目标策略组、规则集引用和最终 MATCH；错误显示行号。并发修改返回 409，管理员重新加载后再编辑。可通过「恢复文件模板… → 确认恢复文件模板」撤销后台覆盖。接口为仅超级管理员可访问的 `GET/PUT /api/subscription/rules`；PUT 必须附带 GET 返回的 `revision`。

「订阅安全设置」支持永久、3 分钟、1 小时、1 天、7 天及自定义秒数。`ttl_seconds=0` 表示永久，其他允许值为 30–315360000 秒。仅对新签发的链接生效；旧链接保留签发时的期限。永久链接仍受账号/套餐到期、流量限制、来源规则、撤销、重新签发及单次使用约束；返回的 `expires_at` 为 `null`。永久链接不在浏览器存储中持久保存。

续期仍限制单次 1–3650 整数天，超限会在输入框下提示；后端返回字符串、字段对象或验证数组时，前端统一转成文字，避免 Toast 引发页面渲染异常。

性能调整包括静态背景渐变、降低玻璃模糊半径、去掉弹层背景模糊，以及缩小用户表与统计组件的状态订阅范围，减少打开编辑器时整表重渲染。

## 策略组排序

`v0.8.4-mgma.27` 在「Clash 规则编辑器」顶部增加「策略组排序」。展开面板可对模板策略组上移、下移或置顶，点击「保存排序」后，下次更新 Clash、Mihomo 或小火箭订阅即生效。「恢复模板顺序」撤销自定义顺序。

公共及用户私有的外部订阅聚合组和来源组始终排在末尾，不出现在可排序列表中。这里只改变策略组在客户端的显示顺序，不改变规则匹配顺序、组内成员顺序、节点、授权或默认选择。没有自定义顺序时保留模板的普通组顺序；模板新增组接在已排序的普通组后，删除的旧组自动忽略。

仅超级管理员可读写 `GET/PUT /api/subscription/group-order`。`group_names` 必须恰好包含当前全部普通模板组且不重复；传 `null` 恢复模板顺序。保存需携带 `revision`，并发修改返回 409，重新加载后可再保存。排序与规则使用独立的版本，不会相互覆盖。

## 发布与回滚

新增迁移 `7a24d91b6e03`，只放宽 `mgma_settings` 有效期 CHECK 约束并新增 `subscription_rules` 表。升级前需对在线 SQLite 做备份，在副本执行 `alembic upgrade head`、`PRAGMA integrity_check` 并核对原业务表行数与模板规则数。正常升级不改变现有 180 秒配置，不修改现有订阅规则，不重新签发用户链接。

回滚使用成对的旧镜像和升级前数据库备份；保留升级后的数据库以便核对恢复期间的新写入。不要用旧代码读取新永久链接，或在仍有新写入时盲目覆盖数据库。

`v0.8.4-mgma.27` 新增迁移 `93f6d024bc58`，仅创建独立的 `subscription_group_order` 表，不重写规则、模板、节点或现有链接。

## Claude 独立选点

`v0.8.4-mgma.28` 提供 `clash/easyus.yml` 部署模板，将 Claude 与 Anthropic 的 8 条既有规则指向 `🤖 AI 服务-Claude`。其他 AI 服务仍走 `🤖 AI 服务`。使用自定义模板目录的部署需同步其中的 `clash/easyus.yml`；已保存的数据库规则优先于模板，应按需同步相关目标。

Claude 组保留普通节点组及 DIRECT 选项，并直接列出当前用户订阅已授权的 `MGMA-EXT · …` 节点，可独立选择具体外部节点。只有这个组增加直接成员；其他策略组与外部来源组的隔离和排序保持原有行为。无外部节点时仍可选择原有出口。Clash、Mihomo、小火箭均在更新订阅后生效。
