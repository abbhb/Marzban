# 用户私有外部订阅（v0.8.4-mgma.26）

用户门户新增「我的外部订阅」，可添加公开 HTTPS Clash/Mihomo 订阅链接，或直接导入 Clash YAML 快照。支持修改名称、替换/移除链接、手动刷新、查看节点、关闭混入和删除。私有订阅与套餐节点一起出现在该用户的 Clash、Mihomo 和小火箭配置中；用户下次更新客户端订阅生效。无须重新签发现有订阅链接，账号、套餐、来源、流量及有效期校验继续生效。其他格式沿用原来的导出行为。

私有来源只导入节点，不导入上游规则、策略组、DNS 或脚本，统一使用后台模板和规则编辑器。链接和节点凭据加密存储，列表及节点详情不回显链接、密文或节点凭据。界面明确告知用户：超级管理员可管理私有订阅。

管理后台「外部订阅」显示公共及全部用户的私有来源，可按公共/私有筛选，搜索名称、所属用户名或账户 ID。超级管理员可以编辑元数据、替换/移除凭据、刷新、导入快照、查看节点及删除私有来源。现有管理端创建动作仍创建公共来源。私有来源不能绑定公共套餐，所属账户创建后不可转移；两个用户可以使用同名订阅或策略组，导出时自动处理同名冲突。

公共来源的「启用自动更新」保持原语义：关闭定时刷新后仍分发最后一次有效节点。私有来源的「启用混入和自动更新」关闭后停止混入，保留快照以便重新启用；手动刷新仍可用。移除链接只停止远程拉取，保留已导入节点；要停止混入请关闭开关或删除来源。

每个账户最多 10 个私有来源，合计最多 1000 个节点、2 MiB 解密后节点 JSON。私有预算独立于公共套餐的 5000 节点/8 MiB 预算，避免用户私有来源的变化阻断公共套餐刷新。每个远程响应仍最多 2 MiB、1000 节点；使用现有 HTTPS 公网地址、DNS/IP 固定连接、重定向逐跳校验和超时限制。用户创建、导入、替换链接及手动刷新合计限 20 次/10 分钟（单进程）。候选快照超限时保留最后一次有效节点。

接口：`/api/portal/external-subscriptions`（GET/POST），`/{id}`（PUT/DELETE），`/{id}/credential`（POST/DELETE）、`/{id}/refresh`（POST）、`/{id}/snapshot`（POST multipart）、`/{id}/nodes`（GET 分页）。账户身份来自门户 token，不能通过请求体指定或转移所属用户。访问其他用户或公共来源统一返回 404；管理员 token 不能代替门户 token，普通管理员不能使用超级管理员接口。已有 `/api/commerce/admin/external-subscriptions` 接口继续管理全部来源，响应增加 `owner_account_id`、`owner_username`，公共来源为 null。

## 升级与回滚

迁移 `82e5c913ab47` 为来源新增账户归属及受 CHECK 约束的命名范围，将原全局名称/策略组唯一约束改为范围内唯一。所有已有来源保持公共，源 ID、节点 ID、套餐选择和原有配置均保留。升级前保留旧镜像及 SQLite 一致性备份，并在副本核对表行数、外键、完整性及订阅导出。

回滚应配对恢复升级前数据库及旧镜像，先保留升级后的数据库，核对期间的新写入。存在私有来源时，迁移 downgrade 会拒绝执行，避免将私有来源意外转为公共来源。
